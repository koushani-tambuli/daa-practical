# Design and Analysis of Algorithms (DAA) 📚

A collection of **DAA practical programs implemented in C** as part of my academic coursework.

This repository contains implementations of different algorithms that I have learned and practised during my DAA course. It serves as a reference for understanding algorithm design, problem-solving approaches, and their implementation in C.

This is a student learning repository, and the programs reflect my practical learning journey.

## 📌 Algorithms Implemented

### 1. Graph Algorithms
- Breadth First Search (BFS)
- Depth First Search (DFS)
- Dijkstra's Shortest Path Algorithm
- Bellman-Ford Algorithm
- Floyd-Warshall Algorithm

### 2. Minimum Spanning Tree
- Prim's Algorithm
- Kruskal's Algorithm

### 3. Sorting Algorithms
- Merge Sort
- Quick Sort
- Heap Sort

### 4. Greedy Algorithms
- Fractional Knapsack
- Job Sequencing with Deadlines

### 5. Dynamic Programming
- Matrix Chain Multiplication (MCM)

### 6. Backtracking Algorithms
- N-Queens Problem
- M-Coloring Problem

### 7. Divide and Conquer
- Max-Min Problem

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/koushani-tambuli/daa-practical.git
```

### 2. Navigate to the project directory

```bash
cd daa-practical
```

### 3. Compile a C program

For example, to compile BFS:

```bash
gcc bfs.c -o bfs
```

### 4. Run the program

**Windows:**
```bash
bfs.exe
```

**Linux / macOS:**
```bash
./bfs
```

You can follow the same process to compile and run the other programs by replacing the filename.
